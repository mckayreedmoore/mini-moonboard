# Panel datum grid

This document records the unambiguous center datums reconstructed from the
official [metric](https://moonclimbing.com/media/moonboard-pdf/Mini_MoonBoard_Template_Guide_Metric.pdf)
and [imperial](https://moonclimbing.com/media/moonboard-pdf/Mini_Moonboard_Template_Guide_IMPERIAL.pdf)
Mini MoonBoard template guides. It does **not** specify drilling diameters,
counterbores, T-nut types, or LED hardware.

## Coordinate system

- The origin `(0, 0)` is the lower-left corner of the main sloped climbing
  surface, viewed from the climbing side.
- Positive x runs right across the face; positive y runs toward its top.
- Values generated by the model use the metric template as canonical.
- The kicker is below the main surface, so its y coordinates are negative.

## Main T-nut centers

The columns are A through K and the rows are 1 through 12:

```text
x(column) = 200 mm + 200 mm * zero-based column index
y(row)    = 80 mm + 200 mm * (row - 1)
```

This puts A1 at `(200, 80) mm` / `(7.8740, 3.1496) in` and K12 at
`(2200, 2280) mm` / `(86.6142, 89.7638) in`.

## LED centers

Each LED row is 100 mm below its corresponding T-nut row and uses the same
column centers:

```text
x(column) = x of corresponding T-nut
y(row)    = y of corresponding T-nut - 100 mm
```

The LED datum paired with row 1 is therefore 20 mm below the main-panel edge,
on the kicker. This matches the separate 20 mm dimension on the metric guide.

## Generated table

[`exports/mini_moonboard_metric_template_datums.csv`](../exports/mini_moonboard_metric_template_datums.csv)
contains all 132 T-nut centers and 132 LED centers in millimetres and decimal
inches. Regenerate it with:

```bash
uv run python -m mini_moonboard.export
```

Decimal-inch values in the CSV are exact conversions of the canonical metric
coordinates, not transcriptions of the independently rounded imperial guide.

## Intentionally unresolved

Do not drill from this datum table alone. Before holes are added to CAD or a
fabrication drawing, verify:

- actual T-nut and LED hole diameters and any face orientation requirements;
- the chosen metric or imperial template printed at 100 percent scale;
- the template calibration measurements against the physical print;
- actual panel size and the 2437/2438.8/2440 mm width discrepancy documented
  in [`requirements.md`](requirements.md); and
- the separate kicker foothold pattern, whose dimensions are not represented
  by the regular A-K / 1-12 grid.

# Outer-header barrel bolt: recessed-head trial

The [finite probe](../../scripts/owner_barrel_outer_header_recess_probe.py) tests
all four outer-post/header bolts in the full kerf-right barrel-only assembly.
It changes no panel, side rim, post, frame-bolt, or fixed screw position. This
is a *conditional* geometry alternative, not a cut or drilling instruction.

The current flush-header bolt shaft overlaps its side rim by 52.286 mm³ per
row. In a provisional recessed trial, a 25.4 mm washer envelope, 11 × 4 mm
head envelope, and 1.651 mm washer thickness sit in a 25.4 mm diameter,
6.651 mm deep header recess. The head top is nominally 1 mm below the header
top. These are trial dimensions, not confirmed delivered hardware or tool
requirements.

| Four-row result (each) | Nominal value |
| --- | ---: |
| Recessed stack / installed side rim overlap | 0 mm³ |
| Counterbore / side rim overlap | 0 mm³ |
| 20 × 40 mm driver path / installed rim overlap | 12,252.211 mm³ |
| Driver path / other wood with side rim removed | 0 mm³ |
| Counterbore coverage by header | 100% |
| Header wood below recess | 31.449 mm |
| Header side-edge margin beside recess | 6.35 mm |
| Nominal bolt tip beyond barrel axis | 23.9 mm |
| Protected inventory / neighboring hardware collisions | none above 1 mm³ |

Thus the nominal installed interference has a possible remedy *only if* the
side rim can be removed before servicing the bolt and installed afterward.
The assembled rim still blocks the driver. The very narrow remaining side
margin is not a strength conclusion; counterbore edge breakout, washer
bearing, header net section, wood splitting, barrel/bolt ratings, delivered
head/washer size, engagement, and an executable repeated assembly sequence
remain open. The current 12 frame bolts and all 66 panel screw axes are
preserved in the model. All four rows remain **REVISE**; no fabrication or
structural release follows from this screen.

Source-bound records and saved result packets retain their original bytes.
For an old relative link that no longer resolves, locate the named file in
this directory or browse the record at its original Git revision. The viewer
routes moved document links to their preserved locations without rewriting
its frozen scenes or mechanics inputs.

Use the catalog's [archive reading groups](design-history.md#archive-reading-groups)
for earlier coordination snapshots, WJ layout studies and solver-method
research. These groups preserve the writeup trail without making old work
orders the starting point for ongoing work.

The chronological working-agreement log is [decision-log.md](decision-log.md).
Files in this folder keep their old names. Some internal links still use
previous paths; use the catalog's evidence links or locate the original path
in Git history. A historical document calling itself “current” does not change
the authority in [current-candidate.json](../../current-candidate.json).

Keep original geometry, viewer assets, results and rejected attempts alongside
the explanatory history. Numerical convergence, geometry fit and strength
acceptance describe different outcomes; preserve those distinctions when
retelling the project.

Archive grouping does not authorize removal or relocation. Earlier helpers,
geometry and saved receipts can still be consumed by the current packet.
Keep their original paths and frozen bytes; follow the
[archive and recovery workflow](../../CONTRIBUTING.md) before pruning any
closed raw run.

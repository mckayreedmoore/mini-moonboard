# Uncut-leg runner layout: decision option

This is a geometric concept, not selected CAD, drilling or a resistance pass.
The current flush assembly remains the authority. The owner is being asked
whether the larger posts and wider base are acceptable before implementation.

## Bounded concept

Right-side coordinates are millimetres; mirror X for the left side:

| Item | Proposed envelope or change |
| --- | --- |
| Rear leg | Preserve full 4x6 thickness, X1219.2–1308.1; omit the recess |
| Floor runner | Shift outward 88.9, to X1308.1–1346.2 |
| Outer front post | One solid nominal 6x6, actual 139.7 square; X1168.4–1308.1, Y−175.7–−36, Z0–238.9 |
| Header and kicker | Retain current 2x6 header and whole kicker geometry initially |
| Runner end planes | Retain current front plane and rear-leg bevel initially |
| Outer post/header angle | Move 12.7 inward to the new post inner face |

The floor-beam outside envelope grows from 2514.6 to 2692.4 mm. This avoids
built-up vertical stock and custom fabricated steel, but changes the preferred
2x6 outer posts and makes them extend beyond the panel edges.

The front timber grip becomes 177.8 mm and the rear grip 127 mm. Approximately
3/8x8-inch and 3/8x6-inch commercial bolts are candidates for dimensional
investigation, not approved substitutions. New shear planes, shank/thread
coverage, washers, stiffness, directed spacing and resistance require actual
geometry and force checks. Existing upper bolt axes are only initial geometry.

## What this does not resolve

Removing the rear-leg recess eliminates that particular taper geometry. It
does not fix the separate lower-rim end-cut screen, qualify the front post's
new connections, or establish current six-case strength. The
[cut-method review](flush-cut-method-review.md) describes the rim's Y/Z
support/cut issue. Changing only the angle's X position does not remove its
dominant in-plane tensile stress diagnostic.

This option requires a material/layout choice beyond the requested bolt and
bracket relocation. No enlarged post or shifted runner has been selected.

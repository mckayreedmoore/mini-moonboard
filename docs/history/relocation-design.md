# Proposed changes for occasional relocation

This is a design proposal, not an implemented hardware revision or teardown
procedure. The existing box frame still uses its generated screw/bolt schedule.
The only implemented geometry adjustment in this review trims both cheek
splice rear corners flush with the cheeks, retaining all four screw positions.

## Proposed moving assemblies

Keep each laminated part permanently bonded. Target two side-wall assemblies
(with side battens and cheeks attached), two removable continuous legs, four
main panels, two kicker panels, and removable transverse/seam assemblies.
Determine which rear members, ribs and seam battens can stay together without
making transport awkward. No new structural splice is proposed in the 8 ft
members; confirm door, stair and vehicle access before shortening any member.

## Priority changes to evaluate

1. Retain the four through-bolts per leg. Specify accessible tool paths,
   washer retention, hardware labels and a reviewed tightening/locking method.
   A captive nut arrangement could simplify handling if access warrants it.
2. Develop reusable panel attachment: evaluate flush machine screws into
   engineered captive nuts or through-bolted backing details at the existing
   panel attachment locations. Do not substitute generic furniture inserts
   without checking withdrawal, pull-through, edge distances and hold clearance.
   The intended benefit is avoiding repeated cutting of threads into plywood.
3. At the chosen side/transverse separation points, evaluate bolted cleats or
   brackets so frame teardown does not repeatedly disturb plywood-edge screws.
   Leave screws at joints that stay assembled. Identify these boundaries in
   the connection schedule before deciding hardware sizes or counts.
4. Add durable part/orientation labels, mating-joint marks and a hardware bag
   list. Add locating features only where dry-fit shows alignment is difficult;
   they do not replace structural fasteners.
5. Use accessible releasable cable retainers and a removable controller mount.
   Remove and protect the continuous LED strips before panel separation; no
   new electrical joints at panel seams. Record actual strip count and routing
   in the [LED guide](v1-led-installation.md).

## Validation needed before adoption

Define maximum moving-module size/weight and demonstrate the intended route.
Dry-fit tool access, bolt withdrawal and panel removal with actual holds and
lights present. Develop a supported lifting/teardown sequence; do not assume
the partially dismantled board stands safely or prescribe removing legs first.
Evaluate selected joints for actual loads, material and repeated assembly,
including inspection/replacement criteria for wood and fastening hardware.
Record a trial disassembly/reassembly and post-move inspection before calling
the design relocatable. No reduced fastener count is proposed here.

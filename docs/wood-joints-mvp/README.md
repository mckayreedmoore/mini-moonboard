## Coordination guidance, September 29

The owner asked for guidance to the running agent after reviewing progress.
Continue the selected whole-frame static-demand approach with applicable
code/product connection checks. Reserve detailed local contact work for a
specific unresolved engineering decision. Prioritize the receiver/load-path
ledger and the four existing gates: conditional floor support, panel withdrawal,
receiver/hardware transfer and member-demand recovery.

Reuse completed comparisons, inventories and reviewed method results within
their recorded limits. Repeat a review or experiment when changed inputs,
failures or a specific unresolved concern justify it. Report which engineering
result became usable and the exact missing input for the next result. Missing
data, a numerical failure and a physical strength failure are different findings.

This guidance changes no acceptance criterion, reviewed geometry or native-run
authorization. The analysis coordinator retains readiness, frozen inputs,
serialized execution and final validation under [AGENTS.md](../../AGENTS.md).
The navigation cleanup leaves analysis files, source snapshots and solver runs
with their current owners.

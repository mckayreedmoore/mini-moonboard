## Remaining evidence

Before any of these catalog leads could describe a matched dimensional
scenario, an applicable source or recorded dimensional check must establish
the actual bolt's 1/4-20 UNC external thread class, full-form/thread-runout
interval, point, length tolerance, and body-to-thread transition together
with the matched nut's class, chamfers, and functional thread height. The
nut must seat with full functional engagement and without smooth shank,
incomplete thread, point, or runout interference. A catalog LT, LG,
LB, or unqualified “Thread Length” field alone does not establish those
positions. Any separate NDS nominal-diameter quarter-thread exception must
use its member-specific screen; for the center-principal-header row that
requires part-specific body/thread dimensions or a measured root diameter /
detailed method.

The dimensional screen is conditional on the current modeled grips,
provisional washer/nut ranges, standard-conforming 1/4 in cap-screw
dimensions, and present geometry. It assigns no bolt/nut/washer capacities,
does not change any axis or stack, and does not authorize an order, drill,
cut, or assembly.

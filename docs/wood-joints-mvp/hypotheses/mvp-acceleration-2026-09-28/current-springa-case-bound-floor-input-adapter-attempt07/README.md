# K12-rear 21-cell selected-floor input proposal

This packet prepares one input-only K12-rear proposal with 21 selected bearing
cells, 79 inactive cells, and 42 active source tangent rows. Its mask is the
stable strict-positive set from the exact rejected 16-cell K12-rear run's
seven-state zero-U 711 normal-interval diagnostic. That diagnostic found six
positive cells released by the 16-cell proposal and one selected cell that was
strictly separated: `floor_lumber_leg_right_0` / `SPR1311`. The six added cells
are recorded in `screen.json`. All 100 normal laws are retained at all seven
states; the projection copies no native force or RF values.

The original K12-rear all-bearing controls remain the physics authority for
geometry, material directions, source loads, SPRINGA laws, and retained
bilateral rows. The rejected 16-cell run is classification lineage only. The
21-cell mask is a diagnostic proposal, not accepted support. Input-preparation
gates passed; parent-owned native readiness and strict response gates remain
pending. This packet makes no corner-demand claim.

`screen.json` uses the shared case-bound diagnostic schema. Its exact source
and method pins are in [`projection-source-pins.json`](projection-source-pins.json).
The prepared model, deck, adapter audit, case-bound context, source pins, and
independent serialized-input audit are case-local in [`k12-rear/`](k12-rear/).
The case-bound input adapter and independent serialized-input audit both
passed, while preserving all 50 physical bodies, 92 candidate axes, twelve
retained leg/runner axes, and 66 Hillman axes. Their full preservation and
transform checks are in `k12-rear/audit.json` and
`k12-rear/parent-serialized-input-audit.json`.

No freeze or native run was made for this proposal. The source paths and hashes are recorded in the case-local manifests; the projector and adapter
refuse to overwrite existing outputs.

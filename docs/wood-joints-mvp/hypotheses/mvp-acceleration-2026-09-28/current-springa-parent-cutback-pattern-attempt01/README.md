# Independent first-increment pattern

All six failed cutbacks repeat five iterations with the same worst-residual node/component sequence. Their residuals scale approximately with load fraction. Dominant nodes belong to the top rail and left side; large correction nodes include the top outer left cleat and upper panel. These are failed-iterate diagnostics only, not forces for those joints or proof of a physical defect.

The bounded solver diagnosis may use this observation to distinguish a step-size issue from an unresolved branch/iteration mechanism. No input, native authority or design geometry is changed.

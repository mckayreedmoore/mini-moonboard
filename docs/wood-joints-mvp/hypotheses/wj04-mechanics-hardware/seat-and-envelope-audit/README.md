# Physical hardware seat and envelope audit

The parent ran this CAD audit against the completed WJ24 object and both
archived response-only hardware profiles. All 64 STEP solids are contained
in their corresponding original collision envelopes. All 64 named seat pairs
have opposed coplanar faces and positive finite common area, with pair gaps
below 1e-6 mm. The run took 1.182343 seconds.

Containment carries the archived nominal wood, cross-stack and protected-part
nonintersection screens to these smaller metal solids. It does not verify
manufacturing tolerances, delivered hardware or structural response. Seat
area establishes geometry only; pressure, stability and resistance remain open.
The older five-wood mesh is from WJ16 and must be reconciled with the final
complete-layout geometry before a same-configuration mechanics claim.

The producer and report bind the hardware inventory and complete-layout
composition/diagnostic hashes. No structural solve was run.

# Source next-method architecture review

**Disposition: bounded clean architecture and provenance; no material finding.**
This review covers the saved-row arithmetic replay and the proposed
CalculiX matrix-output precision preflight only. It does not clear the A12
native force-interval stop or authorize a source edit, build, coupon execution,
candidate export, or acceptance change.

## Identity and ownership

The arithmetic packet has a narrow replay boundary: its Python tool pins the
parent recovery and comparison receipts, projection contract, emitted deck,
raw-H diagnostic, pure-solid assessment metadata, and CalculiX source archive
and member hashes. It reads the saved endpoint coordinates and emitted table
to mirror the source operation order; it neither parses the stiffness matrix
nor reconstructs or solves a state. The stable README and output-pin digests
match `028f9fbd6f8c5c514f3ab08e5113b445681c5cd2445f9ae00e20977b7a92553f` and
`d70466693a8bad39c2acffa42fb465d733a8060c5faffb50f8da781bb65b9de8`.
The documented replay writes to an explicit `/tmp` report, preserving the
retained result receipt; the variable elapsed-time field is disclosed.

The arithmetic comparison keeps the pure-solid compliance operator, raw-H
linear state, recovered endpoint state, emitted spring-table projection, and
saved native nonlinear state distinct. The recorded method pass therefore
does not transfer to the unchanged native interval: the table-force miss and
all 27 raw-H interval failures remain. The high-precision check is expressly
limited to norm/subtraction arithmetic on the saved binary64 endpoint state;
it makes no stiffness-serialization, state-forward-error, or causal claim.

The precision packet is a separate source-only proposal. Its pinned diff
changes only the `.sti` formatting token from `%20.13e` to `%20.16e` and leaves
the `.mas` writer unchanged. The host C receipt demonstrates formatting and
parsing on the recorded host libc only. The README does not present that check
as a CalculiX test: it preserves the current source/build/profile/binary
identity and stages a future, separate build identity behind the retained
free-solid coupon and its independent oracle. The stable precision README and
source-pin manifest digests match
`711f1d71a3ad992d92df81f2e0be8a2db45bd9d32d04c5e0253ea4fcd3d02989` and
`1cc174760cb658614431a75532fcd0603342b6e1559ebc0df935be6310e65981`.
Those preflight pins include the exact source archive/member, proposed patch,
host fixture/receipt, existing build history, coupon/checker, and A12
discrepancy basis. The future coupon gate remains a proposal and is not an
authorization to build or export.

## Bounded conclusion

The artifacts preserve source/operator ownership and the original STOP while
providing a reviewable, hash-bound next-method discriminator and a narrowly
scoped possible precision experiment. No additional architecture prerequisite
is warranted from these packets. Any later coupon result can support only a
separate review of whether a candidate export is warranted; it cannot explain
the A12 discrepancy or adopt a source force by itself.

Review scope excluded `.sti`/matrix reads, numerical recovery, solver build or
execution, Docker, CAD/native work, and shared-input or Git mutation.

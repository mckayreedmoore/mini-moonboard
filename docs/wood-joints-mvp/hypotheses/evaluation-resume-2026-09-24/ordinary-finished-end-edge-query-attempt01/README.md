Each ray starts at a receiver-specific point on the bolt axis, using the pinned axial receiver interval, and is queried 0.01 mm inside both ends and at mid-depth. For each timber, `g` is its declared grain axis and `e = unit(g × a)`, with `a` pointing head-to-nut. Distances are from the bolt centerline in the plane perpendicular to the bolt, along signed `g` and `e` rays to the finished outside profile.

## Conditional NDS geometry screen

The primary method is ANSI/AWC NDS-2024: §§12.1.2.1–.3 define end/edge/spacing measurements; §12.1.3.4 directs bolts to Tables 12.5.1A–D; §12.5.1.2(a) and Table 12.5.1A cover end distance and `CΔ`; §12.5.1.2(b) requires equivalent shear area for loading at an angle to the fastener; §12.5.1.3 and Table 12.5.1C cover edge distance. The current bolt model uses nominal `D = 6.35 mm` (1/4 in; the source bolt STEP models a 3.175 mm shaft radius). The current timber material map is a proposal-only Douglas-fir diagnostic scenario whose longitudinal modulus references DF-L No. 2; it does not verify delivered species, grade, or dimensions ([material map](../ordinary-patch-materials-attempt01/material-map.json), [scenario basis](../../../current-material-scenarios.md)). Actual bolts and lumber have not been observed. The softwood row is conditional on the actual timber being identified as a softwood; grade/property acceptance remains separate.

For softwood parallel-grain tension, Table 12.5.1A gives 7D for `CΔ=1.0` and 3.5D for the `CΔ=0.5` floor: 44.45 and 22.225 mm at this nominal D. For both parallel compression and perpendicular-to-grain end-distance cases, the table specifies 4D at `CΔ=1.0` and a 2D floor at `CΔ=0.5`: 25.40 mm and 12.70 mm. Under §12.1.2.2, the NDS end-distance screen is referenced to a square-cut member end. The base-principal `g−` rays terminate at the angled foot cut; their 256.715/289.715 mm values are geometric distances to that profile boundary and are not counted here as Table 12.5.1A end distances. The shortest square-cut end is 43.350 mm on a rail bolt in the cleat. Only under signed, pure grain-parallel tension toward that end does the local geometric ratio screen as `CΔ = 43.350/44.450 ≈ 0.9753`; it is 1.10 mm below 7D but above the half-factor floor. This is conditional, not a failure or geometry-change direction. For tension at an angle to grain, Commentary C12.5.1.2 permits linear interpolation between the perpendicular-to-grain and parallel-to-grain end-distance requirements; this needs the signed member-force angle. A load angle to the bolt axis is a different case, treated by §12.5.1.2(b)'s equivalent-shear-area method. All square-cut end distances exceed the 4D `CΔ=1.0` requirements for both pure parallel compression and perpendicular-to-grain end-distance cases, and the 2D `CΔ=0.5` floor for both. The displayed 0.9753 is a per-axis preliminary screen: the applicable connection factor is the smallest among its relevant fasteners and shear planes. No connection-level factor or resistance is assigned without the fresh member actions and complete connection grouping.

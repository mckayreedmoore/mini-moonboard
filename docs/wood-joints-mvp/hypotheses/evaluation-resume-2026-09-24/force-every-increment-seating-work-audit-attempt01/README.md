# Force-driven seating prefix: work and impulse audit

The audit covers the immutable snapshot through the 20th accepted increment at
`0.020 s`. It verifies complete DAT monitor and native external-work
observations at every accepted `.sta` time. Accepted increments are
consecutive `1–20`, each `0.001 s`; there are no rejected status attempts or
accepted intervals that skip an input-ramp knot. The snapshot was captured
while the source run was live and is non-atomic across files, so this is a
complete accounting of the captured prefix, not a terminal result.

The producer verifies all 27 source-input hashes from the pinned input freeze
and the recursive eight-file `pilot.inp` include closure. It hashes and scans
the full pinned 353 MB `pilot.dat` in one streaming pass, retaining only
complete `PILOT_MONITOR` blocks. All 20 blocks contain the expected 339 nodes.
It reads the captured `.sta`, `.dat`, `.log`, and `input-freeze.json`; it does
not read source-case outputs or `pilot.frd`.

The actual deck has one `*CLOAD,AMPLITUDE=RAMP_N` card. The helper verifies its
662 nonzero scalar node/DOF terms against the frozen 331-node unit-force
pattern and derives a common scale of `100`. `RAMP_N` is the frozen 101-point
cubic sample table, interpreted piecewise-linearly in `STEP TIME`. Accepted
times from `0.001` through `0.020 s` align with its 1 ms knots. There are no
interior ramp knots skipped by an accepted interval, so endpoint trapezoids
equal the exact piecewise-linear scalar load-factor integral over this prefix.

The complete-field virtual-work projection reaches `q=0.8518465605762559 mm`
at `0.020 s`. The reconstructed cumulative discrete work is
`5.891621650386964 N·mm`; the native external-work total is `5.891622 N·mm`.
The difference, `−3.49613e-7 N·mm`, is inside the report's combined
`1.32318e-5 N·mm` print-rounding bound. At the earlier accepted rows the
reconstructed and native totals also agree within their reported bounds.

The exact serialized scalar-pattern impulse through `0.020 s` is
`0.07208 N·s`; the endpoint-trapezoid total is identical. This is the
time-integrated scalar coefficient multiplying the frozen self-equilibrated
nodal pattern, not a net-resultant vector impulse or transferred contact
impulse.

The work bound covers the projected displacement print quantum, the ramp
amplitude change implied by printed DAT times, and native external-work print
rounding. It excludes solver integration error and any difference between
the discrete work sum and continuous-path work. Agreement does not establish
contact equilibrium, material validity, quasi-static behavior, seating,
capacity, or mechanical acceptance. The report keeps `mechanical_acceptance`
false and identifies the prefix as nonterminal.

# Implicit C3D10 free-MPC coordinate-invariance fixture

Status: preparation only. The two decks and analytical reference are ready
for parent review. No native run, build, or input freeze was performed.

## Question and boundary

This method fixture tests one narrow path: whether CalculiX 2.23 implicit
direct dynamics gives the same C3D10 rigid-translation response in direct
physical coordinates and under one free homogeneous MPC coordinate
substitution. It tests the source-assembled mass matrix's uniform-translation
row sums and transformed physical load vector. It does not qualify arbitrary
C3D10 mass modes, the full mass matrix, or any structural criterion.

Both decks use the straight-sided unit tetrahedron and material from the
explicit C3D10 coordinate fixture: nodes 1–10, one C3D10, `E=1 N/mm²`,
`nu=0`, `rho=6 tonne/mm³`, and volume `1/6 mm³`. The resulting mass is exactly
`1 tonne`. Physical `U2=U3=0`; all ten physical `U1` coordinates remain
available. In the mapped deck only, node 1 `U1` is dependent in the single
homogeneous equation
`u1 + u2 + u3 + u4 - 4*q11 = 0`; controller `q11` is free. This is one
coordinate substitution, not a rigid tie among the physical nodes.

## Loads and discrete known answer

The implicit C3D10 mass path is tested in its rigid-translation mode with the
physical nodal load vector `f=M*1 mm/s²`. For a quadratic tetrahedron,
integrating the shape functions gives `-rho*V/20` at each corner and
`+rho*V/5` at each midside node for unit acceleration. Here that is `-0.05 N`
on nodes 1–4 and `+0.2 N` on nodes 5–10; the sum is `1 N`. The identical ten reference loads, including
the load on dependent node 1 in the mapped deck, are multiplied by a tabular
amplitude with points `(0,0)` and `(0.1,0.1)`. The pinned source linearly
interpolates between table points, so for time expressed numerically in
seconds the target acceleration is `a=t mm/s²`. Initial load and acceleration
are zero; initial velocity and displacement are also zero.

For the load weights, the quadratic tetrahedron corner shape function is
`N_i=L_i(2L_i-1)` and an edge shape function is `N_ij=4L_iL_j`. On a tetrahedron
`integral(L_i dV)=V/4`, `integral(L_i² dV)=V/10`, and
`integral(L_iL_j dV)=V/20` for `i!=j`; hence the corner row sum is
`2V/10-V/4=-V/20` and the edge row sum is `4V/20=V/5`. Multiplying each by
`rho*a` yields the stated force vector and its total `rho*V*a`.

Use `*DYNAMIC,DIRECT,ALPHA=0` with `dt=0.001 s` and period `0.1 s`. The pinned
2.23 manual says `DIRECT` preserves the user increment. The manual's direct
integration section identifies `alpha=0` with classical, nondissipative
Newmark; pinned source sets `beta=(1-alpha)^2/4` and `gamma=0.5-alpha`, giving
`beta=1/4`, `gamma=1/2` here. For each fixed step `n`, with `t=n*dt` in
seconds, the independent scalar recurrence is

```text
a_n = t
u_n = u_(n-1) + dt*v_(n-1)
      + dt²*((1/2-beta)*a_(n-1) + beta*a_n)
v_n = v_(n-1) + dt*((1-gamma)*a_(n-1) + gamma*a_n)
```

Starting from `u_0=v_0=a_0=0`, this gives
`v_n=t²/2 mm/s` and
`u_n=t³/6 + t*dt²/12 mm`. The displacement's `t*dt²/12` term is the
Newmark discrete correction; this contract does not substitute a continuous
trajectory for the actual fixed-step result. At `t=0.1 s`,
`u=0.000166675 mm`, `v=0.005 mm/s`, and `ELKE=0.0000125 N·mm`.

For startup, the pinned `nonlingeo.c` path at lines 1269–1285 computes the
initial acceleration using `M + scal1*K`, with `scal1` proportional to
`beta*(dt/10)²*(1+alpha)`. No load is applied at `t=0`, and initial `u=v=0`,
so the startup right-hand side is zero and the target `a_0=0`; this fixture
adds no stabilization or nonzero initial acceleration. The table's first
value is explicitly zero to avoid a force jump at the start.

The response is uniform U1 translation, so `ELSE=0`; body totals are
`EMAS=1 tonne` and `EVOL=1/6 mm³`. For output time `t`, the expected kinetic
energy is `ELKE=0.125*t⁴ N·mm`. Mapped controller `q11` must match physical U1
and V1. RF is intentionally excluded from the inertia oracle: the independent
check is the nodal motion and kinetic-energy response under the declared
physical loads. The expected time rows are generated by `reference.py` and
stored in `expected.json`.

`8933ca0a5bb9fa3db2b55b4ec9344be9dca1297763f5ea28f6ef7c9074ea84aa`), lines
76–108 evaluate the active amplitude at the current time and linearly

`d009650b48e5ca150080aed9e19d1b65d2b2cf4869ab6d7f2b1a5cd55e2df3fc`), lines
986–1005, assembles implicit C3D10 mass by integrating `rho*N_i*N_j` with a
four-point tetrahedral rule. That rule underintegrates the degree-four mass
integrand, so the ten-scalar-DOF element mass matrix is rank at most four.
This fixture does not use that matrix as a general-mode oracle. Its particular
`M*1` vector is independently determined: shape functions sum to one, and
the four-point rule exactly integrates each degree-two C3D10 shape function.
Thus the matrix row sums equal `rho*integral(N_i dV)` and the listed
corner/midside loads, up to arithmetic precision. The tested rigid translation
has zero strain and does not depend on the untested matrix modes.

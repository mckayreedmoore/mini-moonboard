## Indexing, fields, and source phase

The C offsets match the pinned Fortran contact-element layout. `gencontelem_f2f.f:704–716` stores node count followed by `igauss`, slave face-list index `jj`, and source face-map index; the C code correctly adjusts the one-based `ipkon` pointer. Its `stx` offset is the first integration point’s six values for element `wje`; `springarea` reads row 1 at `igauss`; `ener` reads `ener(1,1,ne0+igauss)`; and `pmastsurf` reads rows 3–6. Pair lookup uses the inclusive `itiefac` range for `jj`. The record includes both that `jj` index and the encoded slave face from `islavsurf`, so downstream decoding must preserve their distinct meanings.

The Fortran `CCXPT_MAP` write supplies 13 integers and 12 reals, matching its format; `CCXPT_UNMAPPED` supplies 10 integers. New locals are declared in the subroutine declaration section, and format labels are placed before its final `end`; executable fixed-form continuation lines fit the source form. The explicit normal arguments retain the same field count without changing `k`. The C `CCXPT_TRIAL` format has 11 `ITGFORMAT` fields and 13 doubles; the `(double)kscale` cast closes the prior mismatch. Parent build04 compiled the exact current hash successfully.

`CCXPT_MAP` logs a signed gap and final generator decision before spring creation. For this dynamic law, positive `clear` suppresses generation; zero is not excluded by the strict `clear>0` test. `CCXPT_TRIAL` reads `stx` and `ener` after the corrected-state `results()` evaluation, after any applicable static line-search reevaluation, and before those arrays are freed. It is a post-solve constitutive evaluation on springs already present in the generated set. Its force is not the load/tangent used for the just-completed pre-correction Newton assembly; the `results()` path updates nodal forces, and the subsequent `calcresidual()` uses those corrected-state forces for the post-correction residual and convergence checks (`nonlingeo.c:3282–3291, 3440–3455`). `springforc_f2f.f:186–201, 248–253` confirms signed linear pressure `-K*clear/kscale` and no clamp for a retained open spring; negative clearance yields positive compressive pressure, while positive clearance can yield tensile trial pressure. Pressure times area gives the signed normal resultant. No friction law is added, and these rows do not measure shear/slip.

The two record families have different phases. There is no adjacent-iteration `vold` snapshot join in this patch, so map gaps must not be matched to `CCXPT_TRIAL` as the same state. It also does not reconstruct force/work for inactive points, establish an omitted-force bound, or qualify the joint. These limits are correctly reflected in the patch lock.

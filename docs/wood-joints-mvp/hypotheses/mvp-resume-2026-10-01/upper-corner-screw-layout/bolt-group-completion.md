## Primary equations and retained arithmetic

The pinned [AWC NDS 2024 Chapter 11](https://awc.org/wp-content/uploads/2026/09/AWC_NDS2024_withCommentary_20260911_Website_Chapter-11-Mechanical-Connections.pdf),
printed p.74, §§11.3.6.1–.3 and Eq.11.3-1, supplies the group-action equation.
Its local source is
`../../upper-block-strength-2026-10-01/source-cache/chapter11-2024-awc-20260911.pdf`,
SHA-256 `45a3d78de1a4fba573589be0fc776e37bd581e4cedec24e38d63856161092d33`.
The official [March 2026 consolidated errata](https://awc.org/wp-content/uploads/2026/03/2024-NDS-Errata-and-Addenda-03.23.26.pdf),
PDF p.7, confirms the wood-to-wood row modulus exponent:
`gamma = 180000 D^1.5`, with D and spacing in inches.

The row equation uses the number of fasteners in a row, spacing, diameter
and the main/side member `EA` terms. Parallel loading uses gross member
cross-section; the specified
perpendicular construction uses thickness times overall group width, with
the single-row width defined by its spacing. Row identity depends on load
direction. The adjacent-row proximity rule also depends on projected
spacing. This is a resistance-equation modulus, not the frame connector spring
or a qualification of delivered wood or dowel stiffness.

The worksheet reuses these existing functions, without executing their
producer entry points:

| Function | Role |
| --- | --- |
| `fea/compact_thick_checks.py::conservative_group_factor` | Original adopted additional equal-EA, total-count row sensitivity; actual diameter, pitch and minimum gross area |
| `retained_group_checks.py::group_factor` | Existing two-fastener NDS arithmetic with the declared dry DF-L E=1,600,000 psi hypothesis |
| `mini_moonboard/nds_2024_group_action.py::evaluate_group_action_factor` | Existing strict row-method readiness boundary; no factor is assigned without its required independent coordinator input record |

Each interface preserves the original equal-EA sensitivity and the available
gross/equivalent-area combinations from the retained-pair method. The latter
use each receiver's minimum saved bearing length times the pair's projection
on that receiver's grain. A zero projected width omits that scenario and
remains a recorded geometry fact; it does not create a zero area or capacity.
The six header interfaces retain the existing header-specific `4D` width
sensitivity. The eight corner interfaces also retain their own saved component
`Cg` scenarios. These are named hypothetical row inputs; they do not bound
all oblique loaded areas or all interacting rows.

For each scenario and case, the comparison is
`max_i(|V_i| / (Z_i * Cdelta_i * Cg_scenario))`. The minimum of the declared
factors supplies the largest finite scenario index. A corner's saved `Cg`
is replaced by each scenario factor, never multiplied again. Its existing
`Cdelta` is applied once. Joined N01 references already contain `Ceg`, which
is likewise applied once. This repeats the adopted *additional sensitivity*
arithmetic on the current force distribution. It does not convert that
sensitivity into an adopted universal group law.

Both bolt vectors and their simultaneous signed axial actions are retained.
Each pair records projected spacing along/across each bolt force and a
bolt-bore force wrench about its mean interface datum. The scalar
`sum(|V_i|) / (Cg * sum(Z_i * Cdelta_i))` is an additional same-state
diagnostic. It is explicitly not a resultant or couple resistance. Duty
summaries take a maximum across their interfaces within the same case;
they never sum maxima from different cases.

The strict path checks common same-sign bolt directions, alignment with the
pair line, supported parallel/perpendicular grain directions, and the
two-receiver scope. For otherwise eligible
records it preserves the complete proposed row input and its identity digest,
then invokes the existing helper's missing-independent-manifest boundary.
This leaf has no independently frozen coordinator row-input manifest and
does not manufacture one by hashing its own payload and calling that an
independent expected digest. Consequently this path assigns no actual `Cg`
or group resistance. A future complete row record must also meet the helper's
alignment and parallel/perpendicular member-area guards; even an isolated row
factor cannot qualify adjoining crossed groups, detailing or local transfer.
The finite sensitivity comparisons above remain available now.

For the two internal pairs, lateral `Cg` is inapplicable: both seats belong

retain the tabulated conditional comparisons. The bounded revision uses these

| State | Finite reference comparator | Remaining applicability boundary |
| --- | --- | --- |
| Nonzero oblique action toward an end | Upper envelope 3.5D minimum tier / 7D full tier of the toward-parallel and perpendicular endpoints | No interpolation, connection Cdelta or oblique physical-failure rule. |

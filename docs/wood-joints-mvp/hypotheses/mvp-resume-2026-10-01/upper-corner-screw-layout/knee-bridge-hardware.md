# Proposed knee bridge: stock hardware profile

Use a **1/4-20 × 6.5-in partial-thread Grade 5** planning class for the four
proposed stacks. The initial normal-transfer packet retained an 8-in Lawson
lead; that length is a conservative occupancy envelope, not the final purchase
profile. A long unthreaded body could prevent the nut reaching the wood seat.
Changing length does not change the prescribed normal-transfer calculation.

Stock leads are K.L. Jack `25C650HCS5Z`, named on its official
[6.5-in substitute listing](https://www.kljack.com/products/25c650hcss/), and
[Fasteners Direct F-42824](https://fastenersdirect.com/1-4-20-x-6-1-2-zinc-plated-hex-head-bolt-grade-5/),
listed as 1/4-20 × 6.5-in zinc-plated Grade 5. These listings establish product
leads. Part-specific partial threading, full-form coordinates and conformity
remain conditional; no delivered part has been inspected or selected.

Pair with the existing conditional Grade 5 1/4-20 metal nut lead
`25CNFH5Z` and two declared **25.4/8.3058/2.5-mm washers per bolt**.
The [normal calculation](knee-spine-reinforcement.md) checks supported mean
wood bearing and conditional axial steel references. Washer material remains
the existing generic 250-MPa comparison hypothesis.

Using the existing over-six-inch, one-inch basic-thread class gives a nominal
onset coordinate of 139.7 mm. That class arithmetic supplies 5 mm before the
earliest nut face; it does not prove the actual coated thread/runout/point or
nut chamfer profile. Request the stated coverage and minimum length with the
matched nut. No new bridge lateral resistance is credited, so a nominal shank
bearing comparison is not substituted for the axial tensile-area check.

If later adopted, four new bolts/nuts and eight washers give **108 / 108 / 216**,
with **66 Hillman screws unchanged**. The current 104-stack order stays frozen;
no extra Lawson pack is inferred from this shorter proposal. Stock lead prices,
package terms and the complete current order total remain unrecorded here.

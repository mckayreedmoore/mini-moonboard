# WJ24 representative hardware identity bridge

This record binds the preserved eight-bolt / sixteen-washer / eight-nut
physical steel mesh to the current WJ24 wood around those same eight axes. It
keeps the old WJ16 mesh fingerprints intact and adds a separate
[identity report](identity.json), generated by
[`wood_joint_wj24_hardware_identity.py`](../../../../scripts/wood_joint_wj24_hardware_identity.py).
The [hash index](sha256.json) binds that report. The helper reads JSON, STEP
hash indexes, and the archived mesh report/deck; it imports no CAD, changes no
archive, and performs no geometry rebuild or solver run.

## Identity evidence

Every `wj04_g7/upper_g7_clearance_n86p9_reversed_rail_hypothesis/<stack>` axis
survives in the WJ24 composition. For all eight, the WJ24 candidate-bore
source-shape SHA-256 exactly equals the WJ16 occupancy-bore fingerprint, and
the ordered head-to-nut receiver IDs match both the WJ16 mechanics report and
the WJ24 hardware schedule. WJ24's composition does not publish a separate
axis-origin vector, so the record carries the pinned WJ16 direction and axis
datum only under that exact bore-shape identity. It does not infer a new axis
from a station name or a rounded bounding box.

The eight directions, underhead origins, first wood-face centers and far
wood-face centers are recorded per axis. Each stack has a modeled 127 mm wood
grip, consisting of the two ordered 88.9 mm and 38.1 mm receivers. The
head-washer wood seat is 2.032 mm from underhead; the nut-washer wood seat and
conditional body-to-root profile transition are 129.032 mm from underhead.
The mesh report classifies each washer's wood-seat face from sampled analytic
geometry. Those labels are geometry descriptors; this bridge assigns no
active contact or tie.

WJ24's four non-principal participant bodies have identical WJ16/WJ24 source
shape hashes and zero reported symmetric difference. The principal changed,
but all ten exact added/removed delta-solid bounding boxes are disjoint from
the full physical-metal envelope of each of its four representative stacks.
The report preserves both the whole-body `REVISE` distinction and the narrower
local identity result; the five-body WJ16 wood mesh is still not a WJ24 wood
mesh.

| WJ04 interface | Physical stack IDs | Ordered wood participants, head to nut |
| --- | --- | --- |
| Lower rail to cleat | `lower_rail_1`, `lower_rail_2` | lower full-stock cleat → lower service rail |
| Lower principal to cleat | `lower_principal_1`, `lower_principal_2` | lower full-stock cleat → center-right principal |
| Upper rail to cleat | `upper_rail_1`, `upper_rail_2` | upper service rail → upper G7 crosscut cleat |
| Upper principal to cleat | `upper_principal_1`, `upper_principal_2` | upper G7 crosscut cleat → center-right principal |

The physical mesh uses four separate solids per stack: one continuous bolt
(head and shaft), a head washer, a nut washer and a hollow nut. WJ24's
composed CAD inventory has five role shapes (`head`, `shaft`, and the three
separate washers/nut shapes); the report records that physical-to-CAD role
mapping explicitly. The conditional `body_to_far_wood_face` geometry profile
uses the historical 152.4 mm nominal bolt model, a 6.35 mm smooth body through
the far wood face, and a cylindrical root sensitivity after that point. It is
not delivered-hardware evidence or a selected WJ24 purchase item. The distinct
`Lb_boundary_root_sensitivity` profile is not the mesh bound here.

## Use by a contact adapter

The old steel mesh's `wood_mesh_bundle_sha256` remains the WJ16 patch inventory
fingerprint it was built against. Do not edit that field to the WJ24 hash. A
future adapter may accept this new report as a second, explicit WJ24 source
binding after it verifies the report hash and all axis, participant, profile,
seat, and local-wood checks. It should retain the two provenance values
separately: the original WJ16 source and the new WJ24 identity bridge.

This only supports geometric identity for these eight representative stacks.
It does not supply a complete WJ24 metal layout, a contact law, stable
constraints, preload, loads, capacity, acceptance, installation evidence,
fabrication release, or drilling release. No physical part or wood was
inspected.

Recheck with:

```sh
python3 scripts/wood_joint_wj24_hardware_identity.py
```

To refresh only these new identity files after their declared inputs change,
run the helper with `--write`. It fails closed if source indexes, archived
mesh members, axis IDs, role counts, receiver ordering, seat datums, or local
wood-geometry checks no longer agree.

# Source and axis plan

The primary accepted this plan through the shared tmux chat before implementation.
The owned scope is only this folder. No native execution, CAD, shared-file or Git
mutation is part of the task.

The earlier [retained bolt audit](../../wj24-retained-frame-bolt-audit.md) and
[retained steel-role map](../evaluation-resume-2026-09-24/current-retained-steel-role-map-attempt02/README.md)
record geometry, hardware policy and role bookkeeping. They do not contain this
candidate's signed current forces for all twelve arrangements. The existing
left/right corner demand and whole-boundary packets include some retained
interfaces, but not a dedicated complete twelve-axis current join. This packet
does not reuse their resistance statements or historical unchanged-layout claims.

The current [finished-feature axis register](../current-finished-feature-register-2026-10-01/axis-features.json)
is byte-pinned at
`bebb4274cdecfb6ad0b0f26850d85a16570c245ea9f7d478c0b05c12b4513e19`.
It supplies the current finite axis, two finished bore patches and finished STEP
binding for each retained arrangement. The register's 92 candidate axes stay
separate. Current axis/source/surface pin manifests and the eight receiver STEP
files are also authenticated. Current source geometry is checked against all
83 geometry-file hashes embedded in each native model.

The three-case [freeze](../upper-frame-joint-review-2026-09-30/freeze.json) is pinned
at `d4ba1c78eb358d25e32819201e9c59e05d425a06d9e4e5cca3dc09d7139ffd73`.
Every model, deck, DAT, response, all-body audit, terminal assessment and recorded
serialization file in its case entries is checked. Candidate/revision/case
identity, all seven increment gates, terminal usability and false source
acceptance flags are required. This is authenticated conditional response
evidence, not an acceptance transfer.

The pinned physical projection contract is
`4ceca771e26e1f1d0bf8efca8e3d77dc6d94194553d95e1fd75652ecf2f3f2d3`.
Its physical-index map, source-pin record and every referenced source are
authenticated. Thirty-six rows bind the twelve retained arrangements:
24 bilateral SPRING2 lateral components and twelve tension-only SPRINGA exterior
seat ties. Each source group/index, native element, node map, law, stiffness,
owner, physical point and signed direction is compared across the three cases.
The A12 input-only projection's load history is not applied to A1 or K12.

Only generic endpoint/floor reconstruction, vector arithmetic and body-balance
functions are imported from the pinned existing
[demand exporter](../mvp-acceleration-2026-09-28/current-corner-native-demand-export-attempt03/produce.py),
SHA `0e6aa1b0ec50e3137d2f431f79365de899d109a5d5c61d37de344c9596681fe8`.
Its production entry point, old corner geometry and resistance helpers are not
called. The retained role is validated as `retained_bolt_lateral_plane`; it is
never relabeled as a candidate-bolt role to reuse a helper.

The independent oracle reads DAT RF tokens directly using its own parser,
reconstructs signed first/second actions for all 756 retained scalar-channel
states, and checks full vectors, rounding radii and reference/origin moment
transport. It does not import the producer or its response parser. Complete
eight-body boundaries are independently compared with the frozen all-body
audit; the oracle's raw-token scope remains the twelve retained arrangements.

Unresolved source maps fail with their named cause. There are no unresolved axes
or receivers in the passing report. Resistance, capacity and hardware
compatibility remain unestablished by this demand-only join.

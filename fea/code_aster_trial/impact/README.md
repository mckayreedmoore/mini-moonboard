# Code_Aster 17.4 one-axis frictionless free-impact fixture

This is a small method check for two freely translating point masses that close
a known gap, compress a unilateral penalty contact, rebound, and separate. It
uses `DYNA_NON_LINE` with implicit average-acceleration Newmark integration
(`BETA=0.25`, `GAMMA=0.5`) and the stock `DIS_CHOC` discrete contact relation.
Code_Aster's v17 manual classifies `DIS_CHOC` itself as a local explicit
penalty law. Thus the fixture checks implicit time integration together with
that documented local impact law; it does not turn `DIS_CHOC` into a physical
contact stiffness.
The command uses an absolute `RESI_GLOB_MAXI=1e-9 N` tolerance. The free
approach has zero contact force, so a relative-only residual criterion is
ill-scaled there.

This is deliberately **not** a continuous `DEFI_CONTACT` surface-contact
model. The one-dimensional pair has no deformable bodies or contact patches,
no stress field with material meaning, and no tangential motion. Setting
`COULOMB=0` removes tangential contact force. The `RIGI_NOR` value is a
numerical penalty selected to give a convenient closed-form contact duration,
not a wood, hardware, or interface property. A pass here cannot qualify
surface contact, a timber joint, another candidate, or a structural capacity.

The command and mesh syntax follow the stock Code_Aster 17.4.0 validation
input [SDND102B `.comm`](https://gitlab.com/codeaster/src/-/raw/17.4.0/astest/sdnd102b.comm)
and [`.mail`](https://gitlab.com/codeaster/src/-/raw/17.4.0/astest/sdnd102b.mail),
which exercise discrete masses, a `SEG2` contact element, `DIS_CHOC`, and
`DYNA_NON_LINE` with Newmark. That stock case is a syntax/formulation
reference; it is not this fixture's known-answer result.

## Model and independent answer

Units are mm, tonne, and s, so force is N and energy is N·mm. The mass centers
start at `x1=0 mm` and `x2=2 mm`; each contact reach is `0.5 mm`, giving a
1 mm open gap. Masses are `m1=1 tonne` and `m2=2 tonnes`; their initial
velocities are `+10 mm/s` and `0 mm/s`. Only axial translation is free. There
are no applied loads, imposed motions, friction, or damping.

The reduced mass is `mu=m1*m2/(m1+m2)=2/3 tonne`. The undamped contact duration
is selected as `Tc=0.08 s`, so `omega=pi/Tc=39.2699081698724 rad/s` and
`kn=mu*omega^2=1028.08379178014 N/mm`. First touch is at `0.10 s`; maximum
compression is at `0.14 s`; separation is at `0.18 s`. For contact-time
coordinate `tau=t-0.10 s`, the independent continuous answer during contact is

```text
delta = (10/omega) * sin(omega*tau)       # positive compression, mm
gap   = x2 - x1 - (0.5 + 0.5) = -delta  # signed free gap, mm
Fn    = kn * delta                       # compressive force magnitude, N
vcm   = (m1*v1 + m2*v2)/(m1+m2) = 10/3 mm/s
v1    = vcm + (m2/(m1+m2))*10*cos(omega*tau)
v2    = vcm - (m1/(m1+m2))*10*cos(omega*tau)
```

Positions follow from center-of-mass translation plus the relative compression.
Before first touch the masses move freely at their initial velocities; after
separation they move freely at the elastic rebound velocities
`v1=-10/3 mm/s`, `v2=20/3 mm/s`. The invariant answers are total momentum
`10 tonne·mm/s` and total mechanical energy
`0.5*m1*v1^2 + 0.5*m2*v2^2 + 0.5*kn*delta^2 = 50 N·mm`.

## Time refinement and inspection

The coarse deck uses `dt=0.0025 s`; the fine deck uses `dt=0.00125 s`. Both
advance to `0.24 s` and align the first-touch, maximum-compression, and release
events. That halves Newmark's time-integration increment while retaining the
same exact event sample times. Compare both discrete results against the
continuous states at matching times, especially the positions, velocities,
signed gap, contact-force magnitude, total momentum, and kinetic-plus-penalty
energy. The oracle is an independent continuous solution, so exact equality
is not expected from finite-step Newmark integration.

all-state comparison passed those pre-frozen limits. The values below are

Halving the step reduced the maximum position, velocity, gap, and derived-force
errors by about 3.995 times. This is a limited method pass for the one-axis
discrete impact fixture only. It does not validate `DEFI_CONTACT` surface
contact, native `SIEF_ELGA` force extraction, frictional response, a timber
joint, or structural capacity. The native logs also report `MODELISA8_14`
because the `POI1` point-mass endpoints belong to the `SEG2` impact element;
that shared topology is intentional in this point-mass fixture.

Each case directory has a self-contained `impact.mail`, `impact.comm`, and
relative-path `impact.export`. The command writes nodal fields to MED and asks
Code_Aster to report its energy-balance table. Use the `N1`/`N2` `DX` and
`VITE` histories to reconstruct momentum and energy independently; derive
signed gap from the input coordinates and `DIST_1/2`, then derive the penalty
force magnitude from `kn*max(0,-gap)`. This does not extract or assert a native
`SIEF_ELGA` contact-force sign or value. The export uses one CPU and is
suitable for the parent-owned serial frozen attempts.

After the parent extracts all nodal MED states to the format emitted by
[`extract_nodal_med.py`](../extract_nodal_med.py), audit the full native
history against the oracle with:

```sh
python3 compare_native.py coarse /path/to/coarse/nodal-history.json --output coarse-comparison.json
python3 compare_native.py fine /path/to/fine/nodal-history.json --output fine-comparison.json
```

`compare_native.py` requires every requested displacement and velocity state,
then reports per-state positions, signed gap, derived force, momentum, energy,
and maximum errors against the continuous answer. The parent audit applies the
pre-frozen numeric bounds described above.
Direct comparison to native `SIEF_ELGA` would require a separate element-field
extractor and sign-convention check.

Offline generation and audit (these do not run or syntax-check Code_Aster):

```sh
python3 generate.py --check
python3 oracle.py --check
python3 audit.py
```

The offline audit confirms generated-input consistency, relative export paths,
event alignment, the analytic unilateral-force sign, and momentum/energy
invariants. `compare_native.py` audits native nodal JSON after extraction. The
native results remain in the linked attempt directories rather than this
fixture packet.

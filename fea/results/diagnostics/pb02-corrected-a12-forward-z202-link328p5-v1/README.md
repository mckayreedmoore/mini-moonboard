# PB02 corrected A12-forward Z202/link-Z328.5 compact evidence

This package retains one developmental `a12-forward` case for the corrected PB02 geometry with
`post_high` at Z = 202.0 mm and `cleat_link` at Z = 328.5 mm. It is not a load-case envelope or a
complete joint qualification.

The package includes the top-level report and diagnostic scope, the converged final-cycle
`cycle-10` input and solver result files, and the complete `source_snapshots` closure recorded by
the report. It deliberately omits earlier cycles, `model.pkl`, and other large raw-run artifacts.
Consequently, it cannot satisfy the full raw artifact manifest referenced by the report.

The selected bolt-axial and face-normal stiffnesses are unqualified developmental trial values.
The lateral stiffness uses the bounded published-basis sensitivity identified in the diagnostic
scope, but the complete joint stiffness remains unqualified. The resulting forces are therefore
developmental evidence only and are not qualified design demands.

This package gives no drilling, fabrication, construction, structural-acceptance, or design
release.

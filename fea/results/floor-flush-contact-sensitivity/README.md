# Preserved flush contact-penalty trials

These compact archives preserve the A12-left trials at timber-face normal
penalties of 10 and 1,000 N/mm³. The original 100 N/mm³ case remains in the
preceding flush evidence. See the
[comparison and limits](../../../docs/floor-flush-contact-sensitivity.md).

Each directory contains a compressed native report, matching geometry, source
snapshot ZIP, manifest and first-stage checker output. The first-stage checks
are not a complete floor-flush release assessment. In particular, a passing
first-stage summary does not resolve the rim end-cut, taper-method, commercial
angle, fabrication, or contact-sampling gates.

These trials vary penalty stiffness only. They retain the same mesh and contact
points, belong to `compact-floor-flush-development`, and do not qualify the
separate uncut-leg investigation. Preserve the source snapshots verbatim.

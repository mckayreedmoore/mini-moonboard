# Native dynamic mass/output controls

Four retained CalculiX 2.21 implicit controls cover one straight or curved C3D10 tetrahedron, each with small-strain geometry or NLGEOM. Generic E=1, nu=0.3 and density=1 use arbitrary consistent units; these are not material properties for the frame. Corner 1 starts with velocity (1,0,0); all other initial velocities are zero. There are no constraints, contact, or applied forces.

`control-ajgbgzoh.tar.gz` contains all four successful controls. `control-axqh8cyi.tar.gz` retains the failed first attempt: CalculiX treats the presence of `EXPLICIT=0` as enabling explicit integration. That attempt finished its solver calculation but failed qualification because there were no accepted implicit STA rows. The corrected decks omit EXPLICIT entirely and retain ALPHA=0. The failed original predates separate solver/analysis exit records; its console and combined exit record preserve that distinction as evidence.

Both archives retain every original file, including frozen helpers and tests, the upstream source snapshot and build manifest, all generated decks, raw DAT/STA/FRD output, command records, logs, exit records, container inspection, and cleanup. The publication manifest hashes every archive member and every accompanying publication file. Original run directories and frozen bytes were not edited.

`mass-blocks.json` caches the source-derived four-point operator and physical Gauss8 operator using the successful frozen helpers in the same immutable image. Its command and logs document a bounded Python postprocessing calculation; no solver was run for publication. Portable replay reads actual U/V and scalar output directly from archived DAT, checks every accepted STA state, recomputes energy and mass with those cached blocks, and checks the final positive-energy, quadrature-contrast, and non-affine-velocity gates. Tests independently rebuild the cached four-point block using tetrahedral shape functions and reference Jacobians. The Gauss8 cache is source-derived evidence, not an independent quadrature proof.

Qualification is limited to native ELKE/EMAS agreement for these untransformed implicit C3D10 fields. It does not validate every matrix coefficient against the solver, native linear/angular momentum, mortar or other contact transformations, time-integration accuracy, a frame, or physical materials. Momentum values retained in comparison reports are reconstructed arithmetic, not independently native-qualified results.

Run `python -m pytest -q tests/test_native_dynamic_control_publication.py` for portable checks, or `python -m fea.publish_native_dynamic_control --verify` for the archived arithmetic replay. Both require no Docker, Gmsh, or FEA execution.
